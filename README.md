# PSX Horror UI Free

**A free PS1 survival-horror menu theme for Godot 4 and Unity, and 9-slice PNGs for any engine.** Set it
in Project Settings and every Button, slider, tab, checkbox and window in your game takes it on,
with the inventory boxes, examine frame, heart monitor, map rooms, files and typewriter save
slots on top.

### Want more?

**[PSX Horror UI](https://heyheythere.itch.io/psx-horror-ui)** has five themes (mansion, fog,
lab, blood and archive) and 100 item icons at 32 and 96 pixels (handgun, revolver, magnum,
shotguns, SMG, grenades, ammo for every calibre, herbs, sprays, pills, 20 keys and keycards,
batteries, flares, files, crowbar, bolt cutters, puzzle pieces and item box). Same files and names: install it over this one.

### What's inside

- **The fog theme** as a Godot `Theme` resource: buttons, option buttons, checkboxes and radio
  buttons, sliders, progress bars, tabs, text fields, panels, windows with title bars, tooltips,
  popup menus, scroll bars and a divider, in the PS1's 15-bit colour with its dither.
- **The survival horror pieces:** menu lines with a pointer, item boxes (plain, selected,
  equipped), the examine frame, the heart monitor with four scrolling ECG traces and bars, map
  rooms and marks, paper for files, save slots, the message box and a 2x headline.
- **9 item icons** at 32x32 and 96x96, rendered from our PS1 models: handgun, handgun ammo, herb,
  first aid kit, old key, flashlight, note, typewriter and ink ribbon.
- **Ribbon**, a typewriter pixel font with printable ASCII and Latin-1, at 1x and 2x, as BMFonts
  that Godot reads directly.
- A mouse cursor at 1x to 4x.
- Every piece is also a plain PNG, with its 9-slice borders in the README and in `slices.json`.

### Compatibility

- Godot **4.3 to 4.7**, tested on both ends.
- **Forward+, Mobile and Compatibility** renderers.
- No scripts needed: the theme is a plain resource.

### Install

Copy `addons/psx_horror_ui/`, set *Default Texture Filter* to **Nearest**, and choose
`themes/fog.tres` under *GUI > Theme > Custom*. `addons/psx_horror_ui/README.md` has the details.
